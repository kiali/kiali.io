The OpenShift Service Mesh Console (OSSMC) is a dynamic plugin for the OpenShift Console that brings Kiali's service mesh observability directly into the OpenShift web console. It adds a **Service Mesh** navigation category with dedicated pages for mesh overview, traffic graph, infrastructure status, and list/detail views for namespaces, applications, services, workloads, and Istio configuration.

For details on what you can do with OSSMC, see the [User Guide]({{< relref "users-guide" >}}). For installation instructions, see [Creating/Updating the OSSMConsole CR]({{< relref "/docs/Installation/installation-guide/creating-updating-ossmconsole-cr" >}}).
